Eileen Santos — Portfolio
Static portfolio: index.html (no build step) + Eileen-Santos-Resume.pdf.
Resume
Eileen-Santos-Resume.pdf is a public version of the CV with the home address and phone number removed. All other content is unchanged. Email and LinkedIn remain.
To update it, replace the file with the same name. To change the name, edit const RESUME='...' near the end of index.html.
Run locally
Open index.html in a browser, or run python3 -m http.server and visit http://localhost:8000.
Publish
GitHub Pages: repo Settings > Pages > deploy from branch main (root). Netlify Drop and Cloudflare Pages also work with this folder.
After deploying, click "Download Resume" on the live URL to confirm the PDF downloads.
